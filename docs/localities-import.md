# Импорт населённых пунктов Беларуси

Справочник живёт в таблицах `geo_regions`, `geo_districts`, `localities`. Витринные города (`cities`) этот импорт не меняет.

Перед первым запуском примените миграции:

```bash
npx prisma migrate deploy
```

## Загрузка из OpenStreetMap

Скрипт запрашивает Overpass API: населённые пункты `place=city|town|village|hamlet` и административные границы `admin_level` 4 (область) и 6 (район). Название берётся из `name:ru`, если его нет — из `name`. Область и район определяются по границам. Для города Минска, если точки нет ни в одном районе, ставится район «Минск».

```bash
npm run import:localities
```

Повторный запуск ищет запись по `osm_id`. Новые строки добавляются, изменившиеся название, тип, район, координаты и население обновляются. Флаги `is_popular`, `is_active`, привязка `service_city_slug` и уже выданный `slug` не перезаписываются.

Другой сервер Overpass:

```bash
OVERPASS_URL=https://overpass.kumi.systems/api/interpreter npm run import:localities
```

Пробный прогон только печатает статистику:

```bash
npm run import:localities -- --dry-run
```

## Файл вместо сети

Сохраните ответ Overpass (`out:json`) и передайте его скрипту. Один файл может содержать и точки, и границы. Два файла — отдельно.

```bash
npm run import:localities -- --file ./tmp/belarus.json
npm run import:localities -- --places ./tmp/places.json --boundaries ./tmp/boundaries.json
```

Файл Geofabrik `.osm.pbf` скрипт не читает: в проекте нет разборщика pbf. Выгрузка Overpass в JSON покрывает ту же территорию и те же теги.

В конце скрипт пишет, сколько строк добавлено, обновлено, оставлено без изменений и пропущено. Пропускаются записи без названия, без координат или без области и района.

## Популярные города

После импорта отдельный сид включает `is_popular` у Минска, Бреста, Гомеля, Гродно, Витебска, Могилёва, Бобруйска, Барановичей, Борисова и Пинска. Если имя встречается и у деревни, берётся населённый пункт с типом `г.` и большим населением. Уже включённые флаги не снимаются, остальные города сид не трогает.

```bash
npm run seed:popular-localities
```
